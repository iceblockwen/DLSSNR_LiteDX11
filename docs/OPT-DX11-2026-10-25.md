范围：本次会话在 `DLSSNR_LiteDX11` 上的**全部代码与配置修改**，包括净保留项、已回滚项、以及回滚原因。

## 1. 净保留的修改

### 1.1 深度链路（`src/nr/depth11.cpp`）

| 改动 | 内容 | 目的 |
|---|---|---|
| 删候选缓存体系 | `Backup` / `Top` / `Eligible` / `TrimCopies` / `BeforeBind` / `BeforeFinish`、`Candidate::copy` / `segment` / `copied` / `copiedInverted` / `knownDirection`、`Context::width/height`、`depth::Bound()` | 原本为了"每帧备份深度再拷回"，改为直接交出活纹理 |
| 排序简化为三层 | 写入优先 → 同尺寸 → 绘制量 | 去掉粘滞赢家与多维打分（用户明确否决） |
| 缺帧不重置历史 | `EndFrame()` 无候选时直接 return | 避免加载期抖动触发历史重启 |
| `Shape()` 放宽 | 允许 0.5×~2× 帧尺寸 | ≤1× 存在"没有有内容深度"的游戏（ROE） |
| 统计拆分 | `total` 记全部绘制、`written` 只记写入绘制 | `written` 只作排序键，不作过滤器（避免断粮） |

### 1.2 深度桥接（`src/nr/bridge.cpp`、`src/nr/shaders/bridge_convert.hlsl`）

| 改动 | 内容 | 收益 |
|---|---|---|
| 输出降到帧尺寸 | `Twin::outWidth/outHeight` = `min(帧, 源)`，只降不升 | 8K 源每帧 ≈531 MB → ≈166 MB（降 69%） |
| 源 typeless 时直连 SRV | 直接 `CreateShaderResourceView` 源纹理，失败才建 staging 备份 | 8K 场景免掉 265 MB 备份拷贝 |
| 转转换 shader 点采样 | `bridge_convert.hlsl` 的 `Depth` kernel 改为 `sx = id.x*iw/ow` 点采样；尺寸相同时退化为逐像素精确拷贝 | 一次 dispatch 同时完成格式转换与降采样 |
| **缩放护栏** | `scaleDepth = guides.width[1]/height[1]/originX[1]/originY[1]` 全为 0 时才缩放 | 游戏声明的深度 subrect 是源纹理像素坐标，缩放会导致 region 与纹理不一致 |

### 1.3 颜色链路（`src/nr/bridge.cpp`、`src/nr/pass.cpp`、`src/nr/frame.hpp`）

| 改动 | 内容 | 收益 |
|---|---|---|
| 删 `native.color` 中转 | `input.resources[0] = buffer.Get()`，backbuffer 直给桥接 | 每帧全屏拷贝 4 → 3 |
| **resolve 直写共享 output** | `Frame12::colorOutput` 把桥接的共享 output twin 交给模型；`Share(output, desc, /*UAV*/true)` 让它带 `BIND_UNORDERED_ACCESS`；`Process` 检测 `result == output.resource` 时跳过 `CopyResource` | 每帧全屏拷贝 3 → **2**（4K BGRA8 每次 33.2 MB） |

护栏：只在 `StorageFormat(format)==format && ViewFormat(format)==format` 时启用（sRGB 会转成 typeless，建不了 typed UAV）；"保留原帧"降级路径与预览路径的 `result` 不等于 output，自动落回旧的拷贝路径。

## 2. 已回滚 / 已删除的尝试

| 尝试 | 结果 | 原因 |
|---|---|---|
| 深度捕获上限收紧到 ≤1× | 回滚 | ROE 的 4K 深度是空壳（每帧 25 draws 全被 `DepthWriteMask=ZERO` 挡掉），≤1× 无有内容深度 → 完全进不了 NR |
| 深度赢家"粘滞" + 多维打分元组 | 回滚 | 加载期本来就会频繁改渲染/resize，跳变是正常的；复杂度不可接受 |
| `ReportMissing()` 逐字段诊断 | 回滚 | 定位完成后无价值 |
| CPU fence 轮询测输入延迟 | 回滚 | 只能观测到"下一帧"，恒 ~16.7 ms，是轮询量化 |
| `SyncQPCTime` 配上屏延迟 | 回滚 | 该交换链拿不到可用帧统计，配对常落到更早的帧，一直 `unavailable` |
| flow 品质三档开关（step25） | 回滚（step27） | 用户要求写死 Low |
| flow 的 R8 loss mask（step26） | 回滚（step30） | 唯一消费者是已删的调试视图；`DLSSNR.ControlMask` 永远传 `nullptr` |
| mask 的 A/B 开关（step28）、懒分配（step29） | 回滚（step30） | 同上；实测勾/关无可辨差异 |

回滚后二进制大小回到 `1244160 B`，与 step24 完全一致。

## 5. 附录 A：可迁移到 DX12 的条目

### 5.1 直接成立（与 API 无关）

1. 输入元数据**只在调用方读一次并向下传**，子函数不再重查（`Describe → Info/Model11`）
2. 身份判断用**指针相等做快路径**，指针不同时才比描述符
3. **常量输入只上传一次**（清零 MV、噪声、LUT），用 `filled` 标志跳过
4. 用不到的资源**根本不创建**（按需桥接），而不是创建后不用
5. 进程级模式开关**收敂成构造期常量**，不进每帧分支
6. 日志分级：`Level=0` 时零字符串构建
7. 状态字段**单写入者**
8. 深度候选选择保持**三层简单排序**，不要粘滞/打分
9. 深度尺寸**上限 2×、输出只降不升**
10. 深度 region 与纹理尺寸必须一致：**游戏声明了 subrect 就不要缩放**

### 5.2 DX12 特有检查点

| 检查点 | 说明 |
|---|---|
| 避免多余中间纹理 | DX11 侧删掉 `native.color` 省一跳；DX12 侧对应"别为了格式/状态插一张中间 RT" |
| 输出直写 | 有 `UAV_TYPED_STORE` 就直接写最终资源，不要"私有纹理 + CopyResource" |
| Barrier 只在状态变化时发 | `before == after` 直接 return |
| descriptor / PSO 池化 | 固定大小 heap + 递增 offset，每帧归零复用（flow 侧 512 槽） |
| GPU 计时 | per-slot `EndQuery(TIMESTAMP)` + `ResolveQueryData` 到 readback，只在诊断等级创建 |
| 不要每帧 `CreateCommittedResource` | 分辨率/格式不变就复用，变化时整体重建 generation 并记录原因 |
| 深度格式族 | `R32_FLOAT` 不属 `R32G8X24_TYPELESS` 族，`D32S8X24` 必须转换；`D32_FLOAT`/typeless 可直连 `R32_FLOAT` SRV |

### 5.3 DX11 专有、DX12 不需要

共享纹理 + `OpenSharedHandle` + 双边 fence + `context->Flush()`，以及跨设备归属校验。
（但"共享纹理加 UAV bind 后由 DX12 直写"这个模式在 DX11 游戏互通场景仍然有用。）

## 6. 附录 B：已确认的坑

| 现象 | 结论 |
|---|---|
| 深度预览"空白" | 预览显示**原始设备深度 × 1.0**；reversed-Z 游戏（近=1、远=0）大部分画面为 0 → 纯黑。开 `Depth contrast`（`pow(1-d,0.125)`）才能看到结构 |
| 一次会话出现多次 `NR layer created` | `SameTuning()`（preset/style/autoMask/uiCorrection/intensity/structure/tone/skin）变化或 `ModelRevision()` 变化都会重建层；面板调参期间属正常 |
| `AutoMask` 与 `ControlMask` | 与 OptiScaler 一致：`ControlMask` 永远 `nullptr`（且每次 create/evaluate 前显式清空，防止复用参数块里的旧指针覆盖开关）；`UseAutoMask` 是唯一开关；模型**只在 create 时读一次** tuning，所以改参数必须重建层才生效 |
| 像素空间 vs UV 空间 MV | 当前送 UV 空间 + `MV.Scale = 帧宽/帧高`（等价且省一次全屏 pass）；R16F 下 UV 空间在超大位移会溢出，像素空间在大位移只有整数精度 |
| Wildlands 必须 `NativeCapture=1` | 该游戏没有 NGX SR 输入，非 cap 路径不会采集任何东西 |
